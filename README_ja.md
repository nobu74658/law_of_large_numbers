# 統計法則のデモンストレーション

このプロジェクトでは、一様分布を用いた数値実験を通じて、以下の基本的な統計法則を視覚的に確認します：

1. **大数の法則**：サンプルサイズが大きくなるにつれて、標本比率が理論的確率に収束することを示します
2. **中心極限定理**：元の分布に関わらず、標本平均の分布が正規分布に近づくことを示します

## 課題内容

実験の内容：
1. 0以上1以下の一様乱数を1回発生させる
2. その値が0.4以下であれば「勝ち」、それより大きければ「負け」とする
3. この実験をn回繰り返し、勝率（勝ちの回数 / n）を求める
4. nを徐々に増やしながら実験を繰り返し、各nにおける勝率を記録する
5. 横軸をn、縦軸を勝率とする折れ線グラフを描く
6. nをどれぐらいにすれば勝率が理論値0.4に収束するかを視覚的に考察する

## 実装内容

### 単一実験（大数の法則）

`law_of_large_numbers.py`スクリプトでは以下の処理を行います：
- 一様分布 U[0,1] から乱数を生成
- 異なるサンプルサイズ（n = 10, 50, 100, 500, 1000, 5000, 10000, 50000, 100000）での勝率を計算
- 対数スケールのx軸を持つグラフ上に結果をプロット
- 理論的確率0.4への収束を表示

### 複数実験（大数の法則）

`law_of_large_numbers_multiple_runs.py`スクリプトでは分析を拡張し：
- 実験を複数回（デフォルト：5回）実行
- 実験間のばらつきを示すために各実行結果を同じグラフ上にプロット
- すべての実行の平均勝率を計算してプロット
- 各サンプルサイズにおける標準偏差などの統計量を計算
- サンプルサイズが増えるにつれて実験間のばらつきが減少することを示す

## 実験結果

実験結果から、試行回数が増えるにつれて観測される勝率が理論的確率0.4に収束することが示されます。これは、試行回数が増えるにつれて結果の平均が期待値に収束するという大数の法則の実証です。

### 単一実験の結果

単一実験の結果から以下のことが観察できます：
- 小さなサンプルサイズ（n < 100）では、勝率に大きなばらつきがある
- nが1000以上に増えると、勝率は0.4に近い値で安定してくる
- n = 10000では、勝率は理論値に非常に近くなる
- n = 100000では、勝率は約0.399となり、理論値0.4に極めて近い値となる

### 複数実験の結果

複数実験では追加の知見が得られます：
- 個々の実験はすべて0.4への収束という同じ一般的な傾向を示す
- 実験間の標準偏差はnが増えるにつれて大幅に減少する
- n = 10では標準偏差は約0.2で、高いばらつきを示す
- n = 100000では標準偏差は0.0015未満となり、非常に低いばらつきを示す
- 複数実験の平均は、単一実験よりも理論値にスムーズに収束する

## 中心極限定理

中心極限定理は、サンプルサイズが大きくなるにつれて、母集団の分布に関わらず標本平均の分布が正規分布に近づくことを示します。

`central_limit_theorem.py`スクリプトでは以下のことを示します：
- 一様分布 U[0,1] からサンプルを生成
- 異なるサンプルサイズ（n = 1, 2, 5, 10, 30, 100）での各サンプルの平均を計算
- これらの標本平均の分布をプロット
- 実際の分布と理論的な正規分布を比較

結果は以下のことを示しています：
- n = 1では、分布は一様（元の分布と同じ）
- nが2, 5, 10と増えるにつれて、分布は徐々にベル型に近づく
- n = 30では、分布は正規分布に非常に近くなる
- n = 100では、分布は正規分布とほぼ区別がつかない

標本平均の標準偏差は理論式 σ/√n に従います（σは元の分布の標準偏差）。

## 組み合わせデモンストレーション

`combined_demonstration.py`スクリプトは、大数の法則と中心極限定理の両方を単一の分析で包括的に視覚化します：

### 特徴：
- 異なるサンプルサイズ（10〜3000）で実験を実行
- 以下を示す2x2のプロットグリッドを作成：
  1. 平均勝率の理論的確率への収束（大数の法則）
  2. サンプルサイズの増加に伴う標準偏差の減少
  3. 小さなサンプルサイズでの勝率分布と正規分布の比較
  4. 大きなサンプルサイズでの勝率分布と正規分布の比較
- 実際の標準偏差と理論的標準偏差を含む統計情報を提供
